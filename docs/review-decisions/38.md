## R-38-98 | architecture | major | fixed

- **Finding**: "Two accounts never share a machine name" is only checked against the workspaces on disk.
- **Where**: MachineName, LinkService, SPEC §8.2 rule 5
- **Reason**: Real, and the maintainer asked for it to be fixed. Each account is a computer of its own for Mnemarr: the pairing and the enrolment send a `computerId` (the hash of the key, 64 hexadecimal digits, no address), and Mnemarr refuses to give a machine that is enrolled on one computer to another. Checked against a real Mnemarr: the other account asking for the name gets a 409, and the same account is told by Mnemarr that it is that machine. The readable name from the address is kept.
