# Configuration

Geminarr is configured **only by environment variables and files**, so that a whole deployment is a manifest ([ADR 0007](adr/0007-geminarr-is-described-as-code-at-three-levels.md)). A setting is an environment variable prefixed `GEMINARR__`; a double underscore is a level (`GEMINARR__READER__POLLMINUTES`). The `GEMINARR__*` names are the supported contract (they are read after `appsettings.json`, so they win over it); the command line is not a channel for settings, and a secret, or the path of one, never goes there (arguments are visible to every process of the host). A secret is given as a **file** (`…FILE`), never as a value. The defaults are in bold; a setting marked with a vertical number does not exist before that vertical (the full list and its meaning are in [SPEC.md §10.2](SPEC.md#102-settings)).

## The container and the page (verticals 0 and 1)

| Variable                                                     | Default                         | Purpose                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| ------------------------------------------------------------ | ------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `GEMINARR__DATAFOLDER`                                       | **`/config`**                   | Where the database and the settings live. A volume; the image's user (uid 1654) must be able to write it. The readiness probe fails when it is missing or read-only.                                                                                                                                                                                                                                                                                                                                                                                          |
| `GEMINARR__URLS`                                             | **`http://+:8282`**             | The address the container listens on. Plain HTTP: publish it through a reverse proxy with TLS and a login in front. The prefixed variable is the one that takes effect (it is read after `appsettings.json`); `ASPNETCORE_URLS` does not. **With a desktop configured, `DESKTOPPORT` is also opened, on the scheme and the host of the first address** (the start is refused when the list is empty or its first address has that port).                                                                                                                      |
| `GEMINARR__PUBLICURL`                                        | none                            | The address of the page as the operator reaches it, for example `https://geminarr.homelab.example` (http or https, a host, no user name). Its host is allowed; it is also the address that goes in the signal that asks for a sign-in. A value that is not one stops the start.                                                                                                                                                                                                                                                                               |
| `GEMINARR__ALLOWEDHOSTNAMES`                                 | **`localhost;127.0.0.1;[::1]`** | The names the page may be reached by (separated by commas, semicolons or spaces; a port is ignored). Any other `Host` is refused (400), the probes excepted: see [network.md](network.md). `*` allows every name (not recommended). Not the `AllowedHosts` key of ASP.NET, which stays `*`.                                                                                                                                                                                                                                                                   |
| `GEMINARR__AUTH__ADMINUSER`                                  | none                            | The name of the operator. **Choose one that is not obvious**: whoever knows it can lock it out for fifteen minutes (five wrong passwords).                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `GEMINARR__AUTH__ADMINPASSWORDFILE`                          | none                            | The file that holds the password of the operator, at least `MINPASSWORDLENGTH` characters, twelve by default (a mounted secret, never an environment variable). It is read at each sign-in: rotating the secret needs no restart. The name and the file are set together or not at all; **without them nobody can sign in** (the container stays alive and closed, and the health says `operator-not-configured`).                                                                                                                                            |
| `GEMINARR__AUTH__COOKIESECURITY`                             | **`Always`**                    | `Always`: the session cookie is `Secure` and named with the `__Host-` prefix (it needs HTTPS). `SameAsRequest`: it is `Secure` only if the request was: **a plain-HTTP sandbox only**.                                                                                                                                                                                                                                                                                                                                                                        |
| `GEMINARR__AUTH__MINPASSWORDLENGTH`                          | **`12`**                        | The shortest password of the operator that is accepted (1 to 1024). **A sandbox only**: lower it only on a machine that nobody else reaches (a build machine on a private network), never in a real deployment. **Refused at start while a browser is configured** (`BROWSER__DESKTOPURL`): the password is also the key to the browser's session.                                                                                                                                                                                                            |
| `GEMINARR__AUTH__SESSIONHOURS`                               | **`12`**                        | How long a session lasts, used or not, from 1 to 720 hours: the operator signs in again after it.                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `GEMINARR__IDENTITY__NAME`                                   | the product's name (`Geminarr`) | The name of this environment, shown at the bottom of the menu (one line, at most 40 characters).                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GEMINARR__IDENTITY__LOGOFILE`                               | none (the product's two rings)  | The path of an image (png, webp or svg of at most 1 MiB, checked by its content) mounted into the container: the picture of the menu. A file that is not usable is not used, and the Settings page says so without its path.                                                                                                                                                                                                                                                                                                                                  |
| `GEMINARR__IDENTITY__COLORS__NAME` / `…COLORS__VERSION`      | `accent`                        | The color of the name and of the version: `#rgb`, `#rrggbb` or a theme token (`accent`, `accentDeep`, `secondary`, `ink`, `inkSoft`, `inkMuted`).                                                                                                                                                                                                                                                                                                                                                                                                             |
| `GEMINARR__MNEMARR__URL`                                     | none                            | The Mnemarr to send to (https; a loopback address is also accepted). When it is not set, the operator gives the address on the page _Mnemarr_ and it is kept in the database. When it is set, the page does not change it.                                                                                                                                                                                                                                                                                                                                    |
| `GEMINARR__MNEMARR__MACHINE`                                 | **`gemini`**                    | The name asked for when a one-time code is exchanged (the first account, when a deployment enrols it by code): 1 to 40 lower-case letters, digits or hyphens. **Every other machine is named from the address of its account** (`geminarr-` and the part before the `@`, [ADR 0026](adr/0026-one-account-signed-in-is-one-machine-of-notes.md)) and is not set here; a pairing lets the person who approves it name the machine, and that name wins. |
| `GEMINARR__MNEMARR__KEYFILE`                                 | per account | Where the key of the machine is kept: a file only the container's user can read. **Without it each account has its own key**, in its own workspace (`<data folder>/accounts/<id>/mnemarr/key`). A key that was given as a file (mounted from a sealed secret) is **one key for the whole deployment, so one machine**: it is used for every account, which then share that machine (use it for a single account). **The key is never in the database, a log or an answer of the API.** |
| `GEMINARR__MNEMARR__ENROLMENTCODEFILE`                       | none                            | A file with a one-time code from Mnemarr (a deployment as code): exchanged for the key of the first account that signs in, when it has none. A code is used once: the other accounts are paired on the page _Mnemarr_. |
| `GEMINARR__MNEMARR__ALLOWINSECUREHTTP`                       | **`false`**                     | A sandbox only: talk to Mnemarr over plain http to a host that is not the loopback.                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `GEMINARR__READER__KIND`                                     | **`None`**                      | `None` (not connected to any assistant: a pass sends what waits and says so), `Web`: the extension of the browser reads Gemini and hands it over ([ADR 0022](adr/0022-the-reader-is-an-extension-in-the-browser-a-person-signed-in-to.md)), or `Demo`: three invented conversations that grow, **for a sandbox only**. The page says when it is on.                                                                                                                                                                                                           |
| `GEMINARR__READER__POLLMINUTES`                              | **`20`**                        | Minutes between two readings (a random 20 % either way is added; doubled for each pass that failed in a row, up to `MAXBACKOFFMINUTES`).                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `GEMINARR__READER__MAXLISTED`, `…MAXOPENPERPASS`             | **`40`**, **`5`**               | How many conversations of the list are looked at, and how many are opened in a pass.                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `GEMINARR__READER__BACKFILLPERPASS`                           | **`10`**                        | How many conversations older than the ones that a pass looks at are also read in a pass, until the list ends (the history is walked slowly on purpose; `0` switches it off, `20` at most). A few hundred conversations take days. |
| `GEMINARR__READER__PASSTIMEOUTMINUTES`, `…MAXBACKOFFMINUTES` | **`5`**, **`360`**              | Reading never lasts longer than the first; a failing reader is read again after at most the second. Whatever the poll interval, the machine says it is alive at least every 10 minutes.                                                                                                                                                                                                                                                                                                                                                                       |
| `GEMINARR__READER__LOGINFAILURES`                            | **`3`**                         | Passes in a row that find nobody signed in before the state is `needs-login`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `GEMINARR__READER__DEMOGROWSECONDS`                          | **`60`**                        | The demonstration reader only: seconds between two new turns.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `GEMINARR__EXTENSION__TOKENFILE`                             | none                            | The file that holds the token the extension presents (a mounted secret, at least 32 random characters, read at each call: rotating it needs no restart, and the policy of the browser changes with it). **Without it nothing the extension sends is accepted** (the health says nothing, the push answers 401).                                                                                                                                                                                                                                               |
| `GEMINARR__EXTENSION__PACKAGEFOLDER`                         | **`extension`**                 | The folder with the signed package and its `extension.json`, relative to the application. The image carries one; a deployment can mount another.                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GEMINARR__EXTENSION__PUBLICURL`                             | none                            | The address by which **the browser** reaches Geminarr (`https://geminarr.homelab.example`, no path), when the address of the request is not it: the update manifest names the package by it.                                                                                                                                                                                                                                                                                                                                                                  |
| `GEMINARR__EXTENSION__ROUNDMINUTES`                          | **`15`**                        | Minutes between two rounds of the extension (1 to 1 440): it says that it is there every half minute, and Geminarr asks for a round when what it said last is older than this. It must be below `GEMINARR__EXTENSION__SILENTAFTERMINUTES` (refused at start otherwise). A round is asked at most once per interval whatever the page answers, so that a block of the assistant is not met by a visit at every heartbeat.                                                                                                                                                                                                                                                                                                                  |
| `GEMINARR__EXTENSION__SILENTAFTERMINUTES`                    | **`45`**                        | Minutes without a word of the extension about the assistant's page (a heartbeat is not one) after which the connection says `extension-silent`, or `unreachable` when the extension still says that it is there (1 to 1 440).                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| `GEMINARR__RETENTION__RUNSDAYS`                              | **`90`**                        | How many days the runs are kept.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `GEMINARR__BROWSER__DESKTOPURL`                              | none                            | The web desktop of the browser container, where a person signs in by hand: a **loopback** address of the namespace the two containers share (`http://127.0.0.1:3000`; anything else refuses the start). Geminarr relays it on an origin of its own (`DESKTOPPORT`), behind a cookie that a ticket of the operator's session gives (ADR 0019); the page _Connection_ opens it. Without it nothing is relayed and the port is not opened.                                                                                                                       |
| `GEMINARR__BROWSER__DESKTOPPORT`                             | **`8283`**                      | The port of the desktop's own origin: a second port of Geminarr that answers for the desktop and nothing else. It is not the page's port. Publish it like the page's (Service, ingress, network policy).                                                                                                                                                                                                                                                                                                                                                      |
| `GEMINARR__BROWSER__DESKTOPPUBLICURL`                        | none                            | The address that the person reaches the desktop by, when a proxy gives it one (`https://desktop.homelab.example`: an origin, no path). By default it is the address of the page on `DESKTOPPORT`. Its host is allowed on the desktop's origin (and only there). **A host of its own is the stronger form** (the default, another port of the page's host, lets a script of the desktop force a sign-out of the operator by overwriting the page's cookie, not take the session over: ADR 0019). It must not be the page's own address (the start is refused). |
| `GEMINARR__BROWSER__REQUIREEGRESSGUARD`                      | **`true`**                      | Geminarr tries, from time to time, a connection that the egress guard refuses at once (ADR 0020), and closes the desktop and the reading while it is not refused. `false` only where the platform cannot run the guard and something else holds its rules (a warning at every start).                                                                                                                                                                                                                                                                         |
| `GEMINARR__BROWSER__ALLOWEDOPENPORTS`                        | none                            | Ports (separated by `;`) that **other containers of the pod open on purpose**, off the loopback, and that Geminarr must not take for the browser being exposed: a service-mesh proxy (Istio's envoy, Linkerd's), a metrics exporter, the test relay of the end-to-end stack. Geminarr reads the sockets of the namespace and closes `/browser/` (reason `browser-exposed`) while anything but its own port, or one of these, listens off the loopback. **Never the desktop's or the debugging port** (the start is refused): they have no sign-in.            |
| `Logging__LogLevel__Default`                                 | **`Information`**               | Standard ASP.NET logging. The logs carry ids, counts, durations and reason codes, **never** the text of a conversation, a password or a cookie.                                                                                                                                                                                                                                                                                                                                                                                                               |

The `GEMINARR__*` names are the supported contract (they are read after `appsettings.json`, so they win over it); the command line is not a channel for settings, and a secret, or the path of one, never goes there (arguments are visible to every process of the host).

**Sessions are in memory**, with the keys that sign the cookies: a restart signs everybody out, and a lockout is forgotten (restarting is the way to lift one early). The page _Settings_ shows what the container runs with, read only.

### The settings of the extension itself

They are not Geminarr's: they are the **policy of the browser** (`3rdparty.extensions.<id>`, see [DEPLOYMENT.md](DEPLOYMENT.md#the-extension-and-the-browser)).

| Policy key    | Default | Purpose                                                                                                                                                                                                        |
| ------------- | ------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `geminarrUrl` | none    | Where the extension sends what it reads, for example `http://geminarr:8282` (the name the browser reaches Geminarr by; it must be one of `GEMINARR__ALLOWEDHOSTNAMES`). Without it the extension does nothing. |
| `token`       | none    | The token, the same as the content of `GEMINARR__EXTENSION__TOKENFILE`.                                                                                                                                        |

## From the next verticals

| Variable                                                    | Vertical | Purpose                              |
| ----------------------------------------------------------- | -------- | ------------------------------------ |
| `GEMINARR__READER__RATELIMITPAUSEHOURS`                     | 4        | The pause after a block |

Every limit and interval comes from configuration with a documented default; none is a literal in the code, except the fixed security policy of the sign-in and an internal cache window, which are stated in [SPEC.md §10.2](SPEC.md#102-settings). A setting that cannot work stops the start with a sentence that names it.
